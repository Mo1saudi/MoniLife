# Expo access diagnostic

The configured `EXPO_TOKEN` authenticates successfully as the Expo robot account `Github` with admin access to `momosaudi`. EAS channel creation is blocked because the existing OMNI LIFE project identifier belongs to a different Expo owner and does not grant this account read access. Use a token from the Expo project owner, or invite `momosaudi` to the owning account/project with an appropriate role before provisioning `preview` and `production` channels.
